# 第5章 代价

镜子又亮了。

【调查组会议室（重现）】

调查组："这份报告，谁让你压下不报的？"

镜中沈知行："是我。苏晴只是照我说的做。"

董事立刻站了起来。

董事："一个敢瞒报人命的CEO，董事会没法再信任你。"

镜中沈知行："我明白。"

当场表决：罢免。

四票赞成，一票反对。

他交出了工牌。

【医院走廊・同一夜】

电话响。

镜中沈知行——此刻已经不是CEO——："我现在就到。"

他跑着冲进医院。

产房门打开的时候，他站在最前面。

真实的沈知行站在走廊尽头，看着那个一无所有、却站在产房门口的自己。

**他以为对的代价，是少赢一点。**

**真正的代价，是连公司都不再是他的。**

**而他，还是选了站在那扇门前。**
