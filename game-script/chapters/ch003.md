# 第3章 赢家的勋章

【董事会・投票前】

周老："隐患没有完全解决，现在铺到全国，还会出事。"

沈知行："修复以后，概率比以前低很多。但不是零。"

周老："那就是还会死人。"

沈知行："现在停，下个月，两百个人没工作，投资人全部撤资。"

会议室很安静。

沈知行："这道题，谁都不想做，但总要有人做。"

举手表决。

周老自己举起了手。

没有人逼他。

（这是第7次"就这一次"——这一次，不止沈知行一个人选的）

投票通过，全国铺开计划启动。

【庆功宴】

香槟举起来，闪光灯亮起来。

台下坐满投资人和媒体，全场鼓掌。

沈知行站在最亮的地方。

他数了一下，从那份被压下的异常报告，到今晚的投票，一共七次"就这一次"。

没有一次，他是存心要害谁。

加起来：死了一个人，毁了苏晴的前程，错过了孩子出生的那一刻。

而且，这套系统明天就会铺到全国的马路上，风险没有归零。

举杯的时候，他对自己说：**我每一次，都只是选了当时看起来对的那个。**

**可是加起来，我好像哪里都错了。**
