# 第4章 如果

【庆功宴后・深夜】

人群散去。

沈知行发现外套口袋里，多了一面裂了缝的旧镜子。

他不记得自己什么时候拿到的。

镜面亮起来，把他拽进一段熟悉的记忆。

【测试部・深夜（重现）】

林野："大雨天，系统有极小概率认错路人。"

镜中的沈知行："发到群里。所有人都要知道。明天，演示停。"

【投资人办公室・第二天】

投资人："你们自己承认有问题，还要我投？"

镜中沈知行："有问题，就不该上路。"

投资人站起来，把合同摔在桌上。

投资人："三年，我没见过这么蠢的CEO。"

当天下午，三个核心工程师递了辞呈，理由都是"看不到前途"。

公司账上，只剩两个月的现金。

真实的沈知行站在原地，想喊"别停"，喊不出声。

他以为接下来是彻底的死——公司死，团队死，一切死。

【三个月后・小办公室】

只剩八个人。

一个新投资人，给了一笔小得多的钱。

镜中的沈知行，头发白了一截，在白板上写："慢一点，但活着。"

没有人死。

真实的沈知行站在那片几乎要垮掉的办公室里，久久没动。

**他以为"对"的代价，是慢一点。**

**他没想到，差一点，就是什么都没了。**
