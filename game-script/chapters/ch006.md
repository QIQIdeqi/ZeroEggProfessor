# 第6章 慢一点的代价

镜子第三次亮起。

【董事会・深夜（重现）】

周老（镜中版本）："隐患没有解决，不能铺。"

镜中沈知行："那就再等。"

一位董事猛地站起来。

董事："你知道这意味着什么吗？投资人撤资，上市黄了，所有人一年的辛苦，全完了。"

镜中沈知行没有退让。

表决。

三票反对延迟，两票支持。

延迟方案，没有通过。

全国铺开，连夜启动——还是上了。

真实的沈知行僵住。

这不是他设想的"好结局"。

【一年后】

没有传来死亡的消息。

不是因为公司听了他，是因为新接手的人，把上线日期偷偷拖了两次，拖到隐患真正修完才松手。

镜中沈知行没能拦住铺开，只拦住了自己，没有再做一次"就这一次"。

事后，他辞职，什么荣誉都没留下。

真实的沈知行终于明白：

**那个"对的决定"，从来不保证结果。**

**它唯一能保证的，是他不会是那个按下警报关闭键的人。**
