# 第1章 我没有错

【测试部・深夜】

林野拿着报告进来。

林野："大雨天，系统有极小概率认错路人。"

沈知行："多小？"

林野："几万次里，一次。"

沈知行："先别发到全公司群里，吓到人没必要。我们俩盯着就行。"

（这是第1次"就这一次"）

【第二天】

问题没再出现。

沈知行："加一道人工巡检，这周先这样顶过去，下周细查。"

（这是第2次"就这一次"）

【投资人来访前夜】

另一个工程师发现一个小异常，报给沈知行。

沈知行："明天投资人要看演示，先别报群里，等演示完我们再处理。"

工程师点头，没再说。

（这是第3次"就这一次"）

【城市道路・大雨・投资人演示当天】

测试车自动驾驶上路演示。

一个过马路的人，被系统认错。

车撞了上去。

那个人，死了。

沈知行站在原地，脑子里过了一遍这几天的决定。

没有一次，他觉得自己在做坏事。

他对自己说：**我每一次，都只是选了"先缓一缓"。**

**加起来，死了一个人。**
