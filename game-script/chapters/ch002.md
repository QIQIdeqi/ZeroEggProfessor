# 第2章 必要的牺牲

【事故调查组・会议室】

调查组查到那份被压下的异常报告。

批准单上，是苏晴的签字。

调查组："这份报告，谁让你压下不报的？"

苏晴看了沈知行一眼。

沈知行没有说话。

（这是第4次"就这一次"——这次，他本可以说一句"是我让她压的"，没说）

【苏晴办公室】

苏晴："调查结果出来了，算我一个人的责任。"

沈知行："……那份报告，是我让你先别往上报的。"

苏晴等着他往下说。

沈知行停在那句话上，没有说完。

（这是第5次"就这一次"）

苏晴记过处分，辞职，没再找工作。

【医院走廊・同一周】

妻子临产，电话一个接一个打进来。

沈知行："我知道。但现在走不开，开完这个会，我马上过去。"

（这是第6次"就这一次"）

会开完了，又多了一个会。

孩子出生的时候，产房外没有他。

他赶到的时候，孩子已经抱出来了。

他对自己说：**我没有一次，是故意不去。我只是每一次，都选了"开完这个会"。**

**加起来，我错过了他出生的那一刻。**
