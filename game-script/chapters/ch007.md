# 第7章 过来人

镜子的光，灭了。

裂镜碎成渣，掉在地上。

沈知行坐在空荡的宴会厅里，一个人。

他看过三次"如果"。

没有一次，是轻松的。

第一次，他们差点彻底破产。

第二次，他把公司和职位，都亲手交了出去。

第三次，他拼了命争取，却连结果都没保住——他保住的，只是自己不再按那个按钮。

**他一直以为，做对的事，只是会慢一点，会少赢一点。**

**他没想到，真正的代价，是可能什么都不剩。**

**而镜子里的那个人，每一次，还是选了那条路。**

他问自己：那个人，到底图什么？

他辞了职，搬出写字楼，没人知道他去了哪里。

【半年后・出租屋】

有人敲门。

他打开门。

对面站着一个人，手里也握着一面裂了缝的镜子。

那个人抬起头。

是林野。

沈知行愣住："你……"

林野："我知道你一直没去找我。"

林野："这镜子，是我放进你口袋的。那天散场，我就站在你旁边，你没看见我。"

沈知行："你早就……"

林野："我见过它给我看的东西，比你看到的，还要难受。"

林野拍了拍他的肩。

林野："我不是来告诉你'没事了'。我是来告诉你，接下来会更难——但这一次，你不用一个人扛。"
