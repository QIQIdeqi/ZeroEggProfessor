# 详细大纲 第4-7章（第二幕 + 结局，2026-11-13 二次修订：加大冲突、改身份反转）

## 第4章 如果
- 场景：庆功宴后独自一人；镜中重现测试部深夜、投资人办公室、三个月后的小办公室。
- 冲突：裂镜现身，沈知行以旁观者重看第1章起点——镜中版选择诚实上报、暂停演示，投资人当场翻脸、三名核心工程师辞职、公司账上只剩两个月现金，几乎彻底破产。
- 结果：三个月后只剩八人，靠一笔小得多的融资续命；没有人死，但代价远比"慢一点"沉重。
- 钩子：**他以为"对"的代价是慢一点。他没想到，差一点，就是什么都没了。**

## 第5章 代价
- 场景：镜中重现调查组会议室、医院走廊（同夜并行）。
- 冲突：镜中版主动揭责，董事会当场表决罢免他的CEO职位（四票赞成一票反对）；同一夜，他——此刻已一无所有——跑去医院，站在产房门口。
- 结果：他失去了公司和职位，但没有缺席孩子出生的那一刻。
- 钩子：**真正的代价，是连公司都不再是他的。而他，还是选了站在那扇门前。**

## 第6章 慢一点的代价
- 场景：镜中重现董事会投票；一年后的结果揭示。
- 冲突：镜中版提议延迟全国铺开，遭董事强烈反对（"投资人撤资，上市黄了"），表决未通过，铺开照常连夜启动——"对的决定"没能改变结果。
- 结果：一年后零事故，但不是因为他赢了投票，而是新接手的人暗中拖延上线直到隐患修完；他本人辞职，什么荣誉都没留下。
- 钩子：**"对的决定"从来不保证结果，它唯一能保证的，是他不会是那个按下警报关闭键的人。**

## 第7章 过来人
- 场景：回到现实的空宴会厅；半年后的出租屋。
- 冲突：镜子碎裂，沈知行明白三次"如果"没有一次轻松——分别是几近破产、净身出户、拼尽全力也未必改变结果；他辞职消失。
- 反转：敲门的不是陌生人，是林野。裂镜是林野在庆功宴散场时悄悄放进他口袋的；林野见过镜子给他看的、比沈知行看到的更难受的东西（内容未展开）。
- 钩子（全书收尾悬念）：**林野："我不是来告诉你'没事了'。我是来告诉你，接下来会更难——但这一次，你不用一个人扛。"**

## 设计说明（本次修订核心）
- 废弃"换个诚实的选择，结果只是慢一点/难一点"的旧版本——这个走向太容易被预判，削弱戏剧性。
- 新版本里，三次"如果"的代价全部**比沈知行实际选的那条路更重**：差点破产、净身出户、努力也未必换来好结果。用这种反差告诉读者："对"不是更轕松的选项，而是他本来就没打算付的那个价。
- 结局反转由"神秘陌生人顾言"改为"林野回归"：顾言这个全新角色削弱了情感重量，林野是第1章被伤害的第一个人，由他亲自带着镜子回来，既有情感闭环，也解释了镜子的来源（他在庆功宴上悄悄放进沈知行口袋），比凭空出现的陌生人更有说服力、更少"神仙来救"的廉价感。
- 林野的具体经历（他见过的、"比沈知行看到的还要难受"的东西）、他如何获得/制作裂镜、接下来"更难的路"具体是什么，均未在本章展开，是续写下一阶段故事的核心入口。
