# 角色档案

## 沈知行（主角）
- 身份：自动驾驶配送车创业公司 CEO。
- 信条：结果说了算，心软是最大的敌人。
- 弱点：把一连串"就这一次"的小决定，当成了无关紧要的权宜之计，从不回头数总账。
- 第1章行为：连续3次用"先别声张""先缓一缓"压下异常报告和小故障，演示当天系统撞死一名路人。
- 第2章行为：调查组追责时沉默，没有澄清报告是他要求压下的，让苏晴独自承担处分；同一周反复用"开完这个会就去"推掉医院探视，错过孩子出生。
- 第3章行为：董事会投票时用真实数据说服所有人（两百人饭碗 vs 已降低但未归零的风险），周老自己举手同意，不是被胁迫。
- 当前状态（第3章末）：达成全部目标，站上庆功宴聚光灯中心；自己数出一共7次"就这一次"，开始意识到"加起来，我好像哪里都错了"，但还没有真正松动自己的信条。
- 第4-6章行为：庆功宴后获得裂镜，以无法被感知、无法干预的旁观视角重看三个结果事件的"如果"版本——每一版代价都比他实际选的更重（几近破产、被罢免CEO、延迟方案未获通过），不是"更干净地赢"，而是"几乎什么都留不住"。
- 第7章状态：认清"对的决定"从不保证结果，只保证他不是那个按错误按钮的人；辞职、消失，独居半年；林野登门，揭露裂镜是他放进沈知行口袋的，提出要陪他走接下来更难的路——全书收在此处，沈知行尚未回应。

## 林野（发小 / 联合创始人 / 第7章"过来人"）
- 关系：与沈知行一起创业的发小，技术负责人。
- 第1章事件：发现大雨场景下的小概率误判问题并上报，被沈知行以"先别声张"的理由按下；事故发生后的真实反应未在正文写明。
- 第7章事件（关键反转）：半年后主动登门，揭露裂镜是他在庆功宴散场时悄悄放进沈知行口袋的；他见过镜子给他看的东西，比沈知行看到的还难受（具体内容未展开）；拍了拍沈知行的肩，表明不是来说"没事了"，而是来告诉他接下来会更难，但这次不用一个人扛。
- 当前状态：第1-6章期间的行踪未知/原文未明确，第7章确认仍在关注沈知行、持有另一面裂镜。

## 苏晴（助理）
- 关系：沈知行的助理。
- 第2章事件：批准单上的签字是她的（沈知行要求她先压下报告），事故调查时沈知行沉默，没有澄清决定是他做的，苏晴独自背处分、辞职。
- 第2章末状态：已辞职，没再找工作，未再出场（第5章"保住苏晴"的版本只存在于镜中，不改变这一真实结果）。

## 周老（董事会成员 / 投资人）
- 关系：沈知行的早期投资人。
- 第3章事件：在董事会上反对隐患未解决就全国铺开，但在沈知行用真实数据说明"停下=两百人立刻失业、投资人撤资"后，自己举手投了同意票，没有被威胁或胁迫。
- 第3章末状态：投票通过，态度未再正面展开，是否仍信任沈知行未知/原文未明确。

## 路人（第1章遇害者）
- 关系：无业务关联的路人，测试车肇事对象。
- 第1章事件：大雨中过马路时被系统误判，当场死亡。
- 状态：身份信息未在正文中明确（姓名、年龄均未知/原文未明确），作为全书第一笔不可逆代价的事实锚点。
