# 《如果》剧情玩法策划案 v0.1

> 本文档面向程序实现，目标：把原剧本《如果（暂定名）》改编为一条**线性叙事 + 3段镜像回放 + 1个真分支结局**的互动叙事流程。
> 核心循环：**选 → 背 → 如果 → 对照 → 悟**（详见设计说明一节的游戏性回顾）。
> 本内容为设计草稿参考，正式落地前需经团队评审与合规审核。

---

## 0. 全局结构总览

```
Ch1 主线(C1 C2 C3)→事故
  → Ch2 主线(C4 C5 C6)→代价累加
    → Ch3 主线(C7)→庆功宴→获得镜子
      → Ch4 镜像1(对C1取反)→对照结局①
        → Ch5 镜像2(对C4+C5+C6取反)→对照结局②
          → Ch6 镜像3(对C7取反)→对照结局③
            → Ch7 收束→真分支(说/不说)→EndingA / EndingB
```

全程线性，无自由跳转、无开放世界；三段"镜像回放"是主干上挂的**短线性支线**，走完自动回到主干，不影响主线剧情顺序。唯一的玩家可控分支在结尾（S7-3）。

## 1. 场景节点流程表

**类型说明**：
- `叙事` = 纯推进，玩家只需点击继续
- `伪选择点` = 二选一按钮，**不改变主线剧情走向**，仅记录玩家倾向用于结尾文案微调（进阶版用，简化版可跳过记录）
- `镜像强制点` = 玩家点击"确认"触发与现实相反的选择（唯一按钮，强调"这次换一条路"的仪式感，而非自由选择）
- `代价结算` = 自动播放的清单动画，玩家点击继续即可
- `真分支点` = 唯一的自由二选一，决定结局

## 2. 关键变量/Flag 一览（供程序建表）

| 变量名 | 类型 | 取值范围 | 写入节点 | 用途 |
|---|---|---|---|---|
| `choice_flavor_C1`~`C7` | string | "A" / "B" | S1-1~S1-3, S2-1~S2-3, S3-1 | 仅文案flavor，不影响主线；进阶版可用于S7结局文案微调 |
| `cost_tally` | string[] | 累加数组，最多3条 | S1-4, S2-2, S2-3 | 驱动"代价清单"UI的逐条追加与S3-2的汇总摊牌 |
| `mirror_item` | bool | true/false | S3-2 | 控制裂镜道具是否已获得，决定是否能进入Ch4 |
| `mirror_path` | int | 1/2/3 | S4-2, S5-1, S6-1 | 标记当前处于哪一段镜像回放，供对照UI取正确的左右列文案 |
| `mirror_memory_count` | int | 0~3 | S4-4, S5-3, S6-3 | 三段镜像的累计收集进度，满3解锁S7正常推进（简化版可直接硬跳转，不做门槛判断） |
| `ending_branch` | enum | A_reveal / B_silence | S7-3 | 决定进入EndingA还是EndingB |

## 3. 交互组件规格（UI/程序对接用）

1. **伪选择点组件**：二选一按钮，点击后仅播放一句分支补白文本，随后自动合流回现实台词继续播放。不产生存档分叉。
2. **镜像强制点组件**：单按钮"确认"，无取消选项——强调"这次他真的换了一条路"，不是玩家自由选，而是玩家代他完成这个动作。
3. **代价清单UI**：底部常驻小条，`cost_tally`每新增一条触发一次滑入动画；S3-2触发"汇总展示"特殊态（三条同时居中展开+淡出）。
4. **对照UI**（S4-4/S5-3/S6-3专用）：左右两栏卡片，左栏标题"真实的代价"，右栏标题"如果的代价"，内容取自上表对应节点，不支持跳过动画（保证情绪节拍）。
5. **真分支点组件**：S7-3是全流程唯一的自由选择UI，建议按钮文案直接用"说出真相"/"不说真相"，不加解释性文字，避免剧透两条结局内容。

## 4. 设计说明（对应前轮已确认的玩法框架）

- 7次"就这一次"做成**伪选择点**而非真分支，是为了保留原剧本"沈知行没有一次存心作恶、却步步走向事故"的宿命感——如果这里做成自由分支，反而削弱了"小妥协会累加"的核心命题。
- 3段镜像回放对应原剧本"他看过三次如果"，分别精确取反C1 / C4+C5+C6 / C7这三个节点，与原文"三次重现"一一对应，不多造支线。
- 唯一的真分支放在结局（说/不说真相），呼应林野最后那句"这次你不用一个人扛"——这是全剧唯一一个不在原剧本里、真正交给玩家的决定。
